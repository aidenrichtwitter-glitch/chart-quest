# Chart Quest

Game Boy-style technical analysis battle game (Phaser 3).

## Play

Open [index.html](./index.html) in a browser (needs internet for the Phaser CDN), or visit the GitHub Pages site once enabled.

**Controls:** arrow keys · Z / Enter / Space confirm · X / Esc back · mouse/touch on menus.

## Patterns

Head & Shoulders · Bull Flag · Double Bottom · Rising Wedge

## Rebuild (optional)

Source under `src/`. Run `node src/gen-data.js && node src/build.js` to regenerate `index.html`.
